* QR-based public traceability
* Trace log history
* Hash chaining and digital signature concepts
* Role-based access control
* Audit-oriented system design

**Tech stack:** Java, Spring Boot, MySQL, Docker, React

**Repository:** [AgriTrace](https://github.com/AcidTSB/AgriTraceChain)

### Sketchy

A desktop application for managing audio and music production projects.

**Highlights:**

* Audio project and folder management
* Smart audio file importing
* Built-in music player with waveform visualization
* Audio adjustment features such as speed, pitch, volume, and crossfade
* AI stem separation for vocals, drums, bass, and other tracks
* Tags, notes, versioning, and quick search
* Offline-first workflow with local data storage

**Tech stack:** Electron, React, TypeScript, JavaScript, Python, Demucs, WaveSurfer.js, Tone.js

**Repository:** [Sketchy](https://github.com/AcidTSB/Sketchy)
